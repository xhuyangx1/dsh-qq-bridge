# 截图说明

README 顶部引用了两张图，放到这个目录即可自动显示：

| 文件名 | 内容 | 建议 |
| --- | --- | --- |
| `qq-chat.png` | 手机 QQ 里的对话 | 竖屏，宽 280px 显示 |
| `settings-page.png` | DSH 设置 → QQ 桥 面板 | 横屏，宽 560px 显示 |

## 截图时注意

> ⚠️ **别把自己的 QQ 号、群号、本机路径截进去。**

- 手机 QQ 截图：把顶部状态栏裁掉，头像打码
- 设置页截图：如果「运行信息」里有你的真实路径，可以切到「NapCat」日志页截，或者裁剪

## 建议裁成什么尺寸

| 图 | 原始尺寸 | 用途 |
| --- | --- | --- |
| `qq-chat.png` | 1080×2340（手机竖屏） | README 里缩到 280px 宽 |
| `settings-page.png` | 1440×900 或 1920×1080 | README 里缩到 560px 宽 |

不用手动缩放 —— README 里已经写死了 `width` 属性。

## 存成什么格式

PNG。截图工具（Windows: `Win + Shift + S`）直接存 PNG 即可。

如果文件太大（超过 1MB），CI 的「没有提交大文件」检查会拦下来。
用 [TinyPNG](https://tinypng.com/) 压一下，或者截图时只截需要的区域。
